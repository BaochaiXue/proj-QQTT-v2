思维导图: Demo v5.1 到底分成哪几条线

先不要按代码文件读。先按这张图看关系：shape prior 是 GPU 1 的一次性结构先验 warmup；普通 warmup 是 GPU 0 的实时感知启动链； actual run 默认是 GPU 0 产出 online chunks，GPU 1 跑 visualize_track.py 看结果。

Demo v5.1 Pipeline 总图

先 warmup，后 actual run；两个 GPU 分工不混在一起。

Shape-prior warmup

GPU 1 managed worker，先 preload，再等 GPU 0 的首个有效请求。

  • shape_prior_warmup.py 管 client / manager / startup。
  • x4 upscaler + SAM3D 在 worker device 上预加载。
  • 只提交一次 frame-0-like request，不是 per-frame loop。

普通 runtime warmup

GPU 0 realtime path，把相机、深度、mask、tracker 热起来。

  • runtime_warmup.py 管 source / FFS / PCD filter。
  • SAM3.1 只做第一帧 mask 初始化。
  • EdgeTAM 和 TapNext++ 进入后续实时循环。

GPU routing

默认 dual warmup，把 heavy warmup/viewer 和 realtime path 分开。

  • GPU 0: camera / segmentation / depth / tracking。
  • GPU 1: shape worker / current visualizer。
  • worker 内部 cuda:0 映射到 physical GPU 1。

Actual run

默认另一边是 visualizer，不是 realtime_phystwin。

  • visualize_track.py 启动在 GPU 1。
  • side-by-side: 左边 input timeline，右边 final_data。
  • optimization_mode=disabled，所以不启动在线优化。

Artifacts / waits

关键等待点是 shape prior 和 35-frame chunk window。

  • shape_prior/points.npz 给 chunk materialization。
  • frames.jsonl 被 chunk bridge tail。
  • final_data.pkl 出来后 visualizer 右侧才有内容。

Code ownership

不要再把 warmup 都理解成一个大 run block。

  • main.py 编排 worker、camera、viewer。
  • shape_prior.py 留给协议、packing、alignment、sampling。
  • realtime_dense_track.py 保留 per-frame loops。
1 GPU 1 worker preload 2 GPU 0 普通 warmup 3 一次 shape-prior request 4 35-frame chunk commit 5 visualize_track.py 显示

source map

代码依据

页面只映射当前代码结构。Warmup 已经拆分：shape-prior 生命周期不再写在 shape_prior.py，普通 startup helper 不再藏在 realtime_dense_track.py 的大块 run 逻辑里。

demo_v5_1/main.py 进程编排、GPU routing、camera subprocess、viewer、可选 optimization。 demo_v5_1/runtime_warmup.py 普通 warmup：source、depth、PCD filter、projection、SAM3.1、EdgeTAM。 demo_v5_1/shape_prior_warmup.py shape-prior client、manager、managed worker startup/preload helpers。 demo_v5_1/shape_prior.py 协议与数据：request/result packing、alignment、sampling metadata。 demo_v5_1/shape_prior_worker.py x4 upscaler、SAM3D mesh、single-view alignment、surface/interior sampling。 demo_v5_1/visualize_track.py 当前 actual run 的 side-by-side point visualizer。 demo_v5_1/config/default.yaml 默认 GPU 模式、shape-prior warmup、viewer layout、optimization disabled。 demo_v5_1/realtime_dense_track.py per-frame segmentation、PCD、tracker、render loop，调用 runtime warmup helpers。
